# Documentation

Contains project documentation for Reflex Logistics.

## Subdirectories

- **architecture/**: System architecture, component diagrams, and design documentation
- **api/**: API contracts, endpoint specifications, and integration guidelines
- **security/**: Security architecture, authentication, authorization, and threat models
- **decisions/**: Architecture Decision Records (ADRs) documenting important technical choices

## Responsibilities

- Capture architectural decisions and rationale
- Define API contracts between frontend and backend
- Document security and compliance requirements
- Provide onboarding and reference material

## What Should NOT Go Here

- Application source code
- Infrastructure configuration
