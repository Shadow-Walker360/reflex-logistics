# Architecture Documentation

This directory contains documentation describing the architecture of Reflex.

## Contents

Architecture documentation may include:

- System architecture
- Component architecture
- Frontend architecture
- Backend architecture
- Database architecture
- Dispatch architecture
- Real-time communication
- Distributed system components
- Integration architecture
- Deployment architecture
- ERD
- Architecture diagrams

## Principle

Architecture decisions should be documented rather than existing only in code or in conversations.

When the implementation differs from the documented architecture, the documentation must be updated.
