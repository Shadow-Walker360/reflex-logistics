# Reflex Client

This directory contains the Reflex frontend application.

## Responsibility

The client is responsible for the user-facing interfaces of Reflex, including:

- Retailer interface
- Dispatcher interface
- Rider interface
- Customer support interfaces
- Administrative interfaces
- Delivery tracking and visualization
- Maps and route visualization
- Notifications and real-time updates

## Technology

The frontend stack will be finalized and documented before implementation.

Expected direction:

- React
- Vite
- TypeScript

## Communication with Backend

The client communicates with the Reflex backend through documented API contracts.

The frontend must not access the database directly.

Client → Backend API → Database
